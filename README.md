# 🗄️ Repositorio de Aprendizaje de SQL

Este repositorio está dedicado a la práctica y estudio de **SQL** (Structured Query Language). Contiene una ruta de aprendizaje progresiva que cubre desde los conceptos fundamentales de las bases de datos relacionales hasta la implementación de consultas complejas y talleres prácticos.

## 📚 Contenido del Curso

El material está organizado por módulos para facilitar el estudio paso a paso:

### 1. Fundamentos
- **1. Hablamos de las bases de datos**: Introducción a los conceptos teóricos, tipos de bases de datos y arquitectura relacional.
- **1. Normalización de los datos**: Técnicas para organizar datos de manera eficiente (1FN, 2FN, 3FN) para reducir la redundancia.

### 2. Diseño e Implementación
- **2. Primera Base de datos**: Creación del esquema inicial y diseño de tablas.
- **3. CRUD**: Implementación de operaciones básicas:
  - **C**reate (Insertar)
  - **R**ead (Consultar)
  - **U**pdate (Actualizar)
  - **D**elete (Eliminar)

### 3. Consultas y Práctica
- **4. Consultas**: Ejercicios de selección, filtrado (`WHERE`), ordenamiento (`ORDER BY`) y agregación.
- **5. Taller 1**: Ejercicios integradores y scripts de consultas avanzadas para poner en práctica lo aprendido.

## 🛠️ Tecnologías Utilizadas

- **SQL**: Lenguaje estándar para la gestión de bases de datos relacionales.
- **RDBMS**: (Puedes especificar aquí cuál usas, ej: MySQL, PostgreSQL, SQLite, SQL Server).
